# 🚀 Scalable Web App with ALB and Auto Scaling

## 📌 Project Overview
This project demonstrates how to build a scalable and highly available web application using AWS services like Application Load Balancer (ALB) and Auto Scaling. It ensures efficient traffic distribution and automatic scaling based on user demand.

---

## 🎯 Purpose
- Handle dynamic web traffic efficiently  
- Ensure high availability  
- Automatically scale resources based on load  
- Improve application performance and reliability  

---

## 🧰 AWS Services Used
- Amazon EC2  
- Application Load Balancer (ALB)  
- Auto Scaling Group  

---

## ⚙️ Key Features
- 🔀 Layer 7 Load Balancing using ALB  
- 🌐 Intelligent routing based on HTTP/HTTPS requests  
- 🔄 Automatic scaling of EC2 instances  
- 🛡️ Fault tolerance and high availability  
- 📊 Health checks for monitoring instances  

---

## 🏗️ Architecture Description
The Application Load Balancer distributes incoming HTTP/HTTPS traffic across multiple EC2 instances. The Auto Scaling Group automatically adjusts the number of instances based on traffic demand. This ensures the application remains responsive, highly available, and cost-efficient.
